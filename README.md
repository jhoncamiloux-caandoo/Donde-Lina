# Donde Lina · Sitio Web & Carta Digital

Plataforma gastronómica digital para Donde Lina (Montería, Colombia), diseñada con enfoque UI/UX de alta calidad (*taste-skill*), textos humanizados y una experiencia dual integrada:

1. **Sitio Web / Experiencia Donde Lina**: Página de aterrizaje visual con fotografías gastronómicas en alta definición, tradición del asado a la brasa y carbón, vitrina de platos con revelación al hacer scroll, video en vivo de productos y llamadas a la acción directas.
2. **Carta Digital & Pedidos**: Menú interactivo por categorías con fotografías, personalización de tamaños, carrito de compras en tiempo real y generación automática de pedidos para WhatsApp (para mesa o delivery).

## Vista local

Abre `carta_digital_donde_lina.html` en cualquier navegador o levanta un servidor estático:

```bash
python3 -m http.server 8000
```

Visita `http://localhost:8000/carta_digital_donde_lina.html`.
